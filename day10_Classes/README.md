# ☕ Day 10 - Classes

## 📚 Introduction

A class is a fundamental building block of Java's object-oriented programming model. It acts as a blueprint for creating objects and defines the data and behavior that objects can have.

A class can contain variables, methods, constructors, and other members.

---

## 📖 Class

A class defines the structure and behavior of objects. It groups related data and operations together into a single unit.

For example, a Student class can contain information such as name, age, and percentage along with operations related to a student.

---

## 📖 Class Members

A class can contain different types of members, including:

- Instance variables
- Static variables
- Methods
- Constructors
- Blocks
- Nested classes

These members define the state and behavior associated with a class.

---

## 📖 Instance Members

Instance members belong to individual objects of a class.

Each object can have its own values for instance variables. Changes made to one object's instance data do not directly affect another object's instance data.

---

## 📖 Static Members

Static members belong to the class rather than to individual objects.

A static member is shared among all objects of that class. Static members are useful when a value or behavior needs to be common to all objects.

---

## 📖 Class and Object Relationship

A class acts as a blueprint, while an object represents an actual instance created from that blueprint.

For example, `Student` can be a class, while an individual student created from the `Student` class is an object.

---

## 📖 Methods in a Class

Methods define the behavior of objects. They contain the operations that an object can perform.

A class can contain multiple methods, and each method can perform a specific task.

---

## 📖 Constructors in a Class

A constructor is a special member of a class that is used when an object is created. Constructors are commonly used to initialize the state of an object.

---

## 📖 Accessing Class Members

Objects can access the instance members of a class. Static members are associated with the class itself and can be shared among multiple objects.

---

## ✨ Advantages of Classes

- Organize related data and behavior together.
- Provide a blueprint for creating objects.
- Improve code organization.
- Support code reusability.
- Provide the foundation for object-oriented programming.
- Make large programs easier to manage.

---
