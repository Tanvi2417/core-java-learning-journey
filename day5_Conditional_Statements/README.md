# ☕ Day 05 - Conditional Statements

## 📚 Introduction

Conditional statements are used to make decisions in a Java program. They allow the program to execute different blocks of code based on whether a specified condition is true or false. These statements help control the flow of execution and make programs dynamic and interactive.

---

## 📖 Types of Conditional Statements

### 1. if Statement
The `if` statement is the simplest decision-making statement. It executes a block of code only when the specified condition is true.

### 2. if-else Statement
The `if-else` statement is used when there are two possible outcomes. One block of code is executed if the condition is true, while another block is executed if the condition is false.

### 3. else-if Ladder
The `else-if` ladder is used to evaluate multiple conditions. The program checks each condition in sequence and executes the block associated with the first condition that evaluates to true.

### 4. Nested if
A nested `if` statement is an `if` statement placed inside another `if` statement. It is useful when one condition depends on another condition.

### 5. switch Statement
The `switch` statement provides an efficient way to select one block of code from multiple alternatives based on the value of an expression. It is commonly used as an alternative to multiple `if-else` statements.

---

## ✨ Advantages

- Improves decision-making in programs.
- Makes code more organized and readable.
- Reduces unnecessary code execution.
- Supports complex logical conditions.
- Enhances program flexibility.
