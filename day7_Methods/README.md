# ☕ Day 07 - Methods

## 📚 Introduction

A method is a block of code designed to perform a specific task. Methods help divide a program into smaller and manageable parts, making the code easier to understand, reuse, test, and maintain.

---

## 📖 Types of Methods

### 1. Static Method

A static method belongs to the class rather than to a specific object. It can be called using the class name without creating an object.

### 2. Instance Method

An instance method belongs to an object of a class. An object must be created before an instance method can be accessed.

### 3. Parameterized Method

A parameterized method accepts values as input. These values allow the same method to perform operations using different data.

### 4. Return Type Method

A method can return a value after performing its operation. The returned value can then be stored or used in another operation.

### 5. Method Overloading

Method overloading occurs when multiple methods have the same name but different parameter lists. It is an example of compile-time polymorphism.

---

## 📌 Important Concepts

### Method Declaration

A method consists of a method name, return type, parameters, and a body that contains the required operations.

### Method Calling

A method executes when it is called from another part of the program. Methods can be called multiple times whenever their functionality is required.

### Parameters and Arguments

Parameters are variables defined by a method to receive input, while arguments are the actual values passed to the method during the method call.

### Return Value

A method can return a result to the calling code. The returned value can be used for further calculations or stored in a variable.

### Reusability

Methods allow the same piece of logic to be reused multiple times without writing the same code again.

---

## ✨ Advantages

- Improves code reusability.
- Reduces code duplication.
- Makes programs easier to understand.
- Simplifies debugging and maintenance.
- Helps divide complex programs into smaller tasks.
- Supports method overloading and object-oriented programming concepts.
