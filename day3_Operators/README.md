---

## 📖 Overview

This module covers the different types of operators available in Java. Operators are used to perform mathematical calculations, compare values, evaluate logical conditions, manipulate bits, and simplify decision-making in programs. Understanding operators is essential for writing efficient and readable Java code.

---

## 📖 Operator Categories

| Category   | Operators              |
| ---------- | ---------------------- |
| Arithmetic | +, -, *, /, %          |
| Unary      | ++, --, +, -, !        |
| Assignment | =, +=, -=, *=, /=, %=  |
| Relational | ==, !=, >, <, >=, <=   |
| Logical    | &&, \|\|, !            |
| Ternary    | ?:                     |
| Bitwise    | &, \|, ^, ~            |
| Shift      | <<, >>, >>>            |

---

## 🎯 Learning Outcome

- Perform mathematical calculations using arithmetic operators.
- Compare values using relational operators.
- Apply logical operators in conditional statements.
- Use the ternary operator for concise decision-making.
- Understand bitwise and shift operations.
- Build a strong foundation for conditional statements and loops.
