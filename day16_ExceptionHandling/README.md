# ☕ Day 16 - Exception Handling

## 📚 Introduction

Exception handling is a mechanism in Java used to handle abnormal situations that occur during program execution.

It helps prevent the program from terminating unexpectedly and allows the program to respond to errors in a controlled manner.

---

## 📖 Exception

An exception is an unwanted or unexpected event that occurs during program execution and interrupts the normal flow of a program.

Examples include:

- Dividing a number by zero
- Accessing an invalid array index
- Using a null reference
- Opening a file that does not exist

---

## 📖 Exception Handling

Exception handling allows a program to detect and handle exceptions so that the remaining part of the program can continue executing when possible.

---

## 📖 try Block

The try block contains code that may generate an exception.

It is used together with exception-handling mechanisms such as catch and finally.

---

## 📖 catch Block

The catch block handles an exception generated by the code inside the try block.

Different types of exceptions can be handled using different catch blocks.

---

## 📖 finally Block

The finally block contains code that is generally executed after the try and catch processing.

It is commonly used for cleanup activities such as closing resources.

---

## 📖 throw

The throw mechanism is used to explicitly generate an exception.

It allows the programmer to create an exception when a particular condition occurs.

---

## 📖 throws

The throws mechanism is used to indicate that a method may pass an exception to the method that calls it.

It is mainly used for declaring exceptions that a method may produce.

---

## 📖 Checked Exceptions

Checked exceptions are exceptions that are checked by the compiler.

The programmer must handle them or properly declare them.

Examples include exceptions related to file operations and database operations.

---

## 📖 Unchecked Exceptions

Unchecked exceptions are generally detected during program execution.

They are subclasses of RuntimeException.

Examples include:

- ArithmeticException
- NullPointerException
- ArrayIndexOutOfBoundsException
- NumberFormatException

---

## 📖 Error vs Exception

An error generally represents a serious problem related to the system or runtime environment.

An exception usually represents a condition that an application can potentially handle.

---

## 📖 Exception Hierarchy

Java provides a hierarchy of classes for handling exceptions.

At a high level:

Object

→ Throwable

→ Exception

→ RuntimeException

Exceptions can have different subclasses depending on the type of problem.

---

## 📖 Multiple Catch Blocks

Multiple catch blocks can be used when different types of exceptions need different handling.

The appropriate catch block is selected based on the type of exception that occurs.

---

## 📖 Custom Exception

A custom exception is an exception created by the programmer for application-specific situations.

Custom exceptions are useful when built-in exceptions do not clearly represent a particular business rule or condition.

---

## 📖 Exception Propagation

Exception propagation occurs when an exception is passed from one method to another through the method call hierarchy until it is handled.

---

## ✨ Advantages of Exception Handling

- Prevents abnormal program termination.
- Separates error-handling code from normal program logic.
- Improves program reliability.
- Makes applications easier to maintain.
- Allows meaningful error messages.
- Helps handle unexpected situations gracefully.

---

## 🌍 Real-World Example

Consider a banking application.

If a user tries to withdraw more money than the available balance, the application should not suddenly terminate.

Instead, it can detect the invalid operation and display an appropriate message.

This is an example of handling an exceptional situation.

---

## ⚠️ Important Points

- Exception handling deals with abnormal situations during program execution.
- `try` is used for code that may generate an exception.
- `catch` is used to handle an exception.
- `finally` is commonly used for cleanup operations.
- `throw` is used to explicitly generate an exception.
- `throws` indicates that a method may pass an exception to its caller.
- Checked exceptions are checked by the compiler.
- Unchecked exceptions generally occur during runtime.
- Custom exceptions can represent application-specific conditions.
