# ☕ Day 04 - Input and Output

## 📚 Topics Covered

- Scanner Class
- User Input
- Reading Different Data Types
- Formatted Output
- Basic Mathematical Calculations

---

## 📖 Overview

This module introduces the Scanner class to accept user input from the keyboard. It demonstrates reading different data types, displaying formatted output, and developing simple interactive Java applications.

---

## 🎯 Learning Outcome

- Accept user input using the Scanner class.
- Read different primitive and non-primitive data types.
- Display formatted output in the console.
- Build interactive console-based applications.
- Apply arithmetic operations using user input.
