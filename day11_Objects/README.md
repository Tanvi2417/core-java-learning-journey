# ☕ Day 11 - Objects

## 📚 Introduction

An object is an instance of a class. It represents a real-world or logical entity and contains its own state and behavior.

Objects are one of the fundamental concepts of Object-Oriented Programming in Java.

---

## 📖 Object

An object is created from a class and represents an actual instance of that class.

For example, `Student` can be a class, while an individual student such as Tanvi can be represented as an object of that class.

---

## 📖 Object State

The state of an object is represented by the values stored in its instance variables.

For example, a Student object can have a name, age, roll number, and percentage. These values together represent the current state of that object.

---

## 📖 Object Behavior

The behavior of an object is represented by the methods defined in its class.

For example, a Student object may have behaviors such as displaying details or calculating a percentage.

---

## 📖 Object Identity

Every object has its own identity. Even when two objects belong to the same class and contain the same values, they are still separate objects.

Object identity allows Java to distinguish one object from another.

---

## 📖 Multiple Objects

A single class can be used to create multiple objects.

Each object maintains its own instance data while sharing the common structure and behavior defined by the class.

---

## 📖 Object as a Parameter

Objects can be passed to methods as arguments. This allows methods to work with the complete state and behavior of an object.

Passing objects to methods is useful when working with related data and complex operations.

---

## 📖 Object as a Return Value

A method can return an object. This allows a method to create or process an object and provide it to another part of the program.

---

## 📖 Array of Objects

An array can store references to multiple objects of the same class.

An array of objects is useful when a program needs to manage multiple entities such as students, employees, products, or customers.

---

## 📖 Reference Variable

A reference variable stores a reference to an object rather than storing the complete object itself.

Multiple reference variables can sometimes refer to the same object.

---

## ✨ Advantages of Objects

- Represent real-world entities in programs.
- Organize data and behavior together.
- Support code reusability.
- Allow multiple independent instances of a class.
- Make large programs easier to organize and maintain.
- Form the foundation of Object-Oriented Programming.

---

## 🎯 Learning Outcome

After completing this module, you will be able to:

- Create and work with multiple objects.
