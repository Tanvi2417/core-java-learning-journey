## 🧠 Interview Questions

### What is Java?
Java is a high-level, object-oriented, platform-independent programming language.

### Why is Java Platform Independent?
Because Java code is compiled into bytecode, which runs on the JVM available for different operating systems.

### Difference Between JDK, JRE and JVM?

| JDK | JRE | JVM |
|-----|-----|-----|
| Development Kit | Runtime Environment | Executes Bytecode |

### Types of Comments

- Single-line (`//`)
- Multi-line (`/* */`)
- Documentation (`/** */`)
