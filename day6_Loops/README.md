# ☕ Day 06 - Loops

## 📚 Introduction

Loops are used to repeatedly execute a block of code as long as a specified condition is satisfied. They reduce code repetition and are commonly used when working with numbers, collections, patterns, and repetitive tasks.

---

## 📖 Types of Loops

### 1. for Loop

The `for` loop is generally used when the number of iterations is known in advance. It provides a structured way to initialize a variable, check a condition, and update the variable during each iteration.

### 2. while Loop

The `while` loop is used when a block of code needs to execute repeatedly as long as a condition remains true. It is useful when the number of iterations is not known beforehand.

### 3. do-while Loop

The `do-while` loop is similar to the `while` loop, but it guarantees that the block of code executes at least once before the condition is checked.

---

## 🔄 Loop Control

Loops can be controlled using statements such as `break` and `continue`.

- **break** is used to terminate the loop immediately.
- **continue** is used to skip the current iteration and proceed with the next iteration.

---

## ✨ Advantages

- Reduces repetitive code.
- Makes programs shorter and easier to maintain.
- Helps process numbers and repeated operations efficiently.
- Useful for solving mathematical and logical problems.
- Forms the foundation for pattern and array-based programming.
